# Smart Waste Collection System

A web platform that lets residents view their neighborhood's waste pickup schedule and report missed or special pickups, while municipal staff manage collection zones, routes, and day-to-day operations from a central dashboard. Built for Rajshahi City Corporation.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Firebase (Authentication & Firestore)

## Getting Started

1. **Environment Setup:** 
   Each teammate must create their own local `.env` file by copying the provided `.env.example` file:
   ```bash
   cp .env.example .env
   ```
   Fill in the shared project's real Firebase keys (do not commit these to version control).

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run the Development Server:**
   ```bash
   npm run dev
   ```
